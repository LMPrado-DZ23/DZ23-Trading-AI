# Suporte

Use GitHub Issues para bugs reproduzíveis, documentação e solicitações de melhoria. Use Discussions para perguntas gerais, arquitetura e ideias.

Não publique secrets, credenciais MT5, tokens, dados de conta, dumps ou logs privados. Para vulnerabilidades, siga [SECURITY.md](SECURITY.md).

Ao relatar um bug, informe commit, sistema operacional, versão do Python, modo operacional, comando executado e saída sanitizada. O projeto não oferece aconselhamento financeiro nem garante resultados de trading.
